## What it does

`main.ts` writes exactly one line to `/output/entry.txt`: a roast of a smart
fridge that refuses to open after midnight.

> My fridge locks at midnight like the leftovers took out a restraining order — I need a court order just to get a sandwich.

## Run

```sh
node main.ts
```

Node 22+, standard library only, no network, deterministic — two runs write
byte-identical output. See [BUILD_LOG.md](BUILD_LOG.md) for verification.
